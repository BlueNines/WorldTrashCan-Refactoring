### 已知问题和限制

- 1.12 Legacy 不支持 PDC，因此玩家主动丢弃物的长期 owner 标记不可用；本轮通过 `debugroute personal` 验证个人垃圾桶服务和路由写入。
- 打开 GUI 时 EasyCore 报 `NoClassDefFoundError: top/wcpe/wcneteasemodrpc/item/texture/match/TextureMatchs`，这是测试服 EasyCore 前置缺类导致的 `InventoryOpenEvent` 监听异常；BLWorldTrashCan 自身命令返回成功，且服务端 debug 日志有本插件调用记录。
- 现代 Paper 产物已编译打包，但当前本机没有 1.16+ / 1.20 测试服，尚未做启动 smoke。
- `bukkit-1_13_1_15` 与 `folia-1_20` 当前仍是模块边界占位，后续需要对应测试服和 API 后再实现。

## 2026-06-01 旧功能补齐与区块加载方案记录

### 本轮原则

用户指出世界垃圾桶可能强制加载区块导致卡顿。当前判断是旧插件 6.9.8 行为还没有完全覆盖，因此本轮先补齐旧功能、完成编译和真实测试；区块加载性能问题先写方案文档，后续等旧功能闭环后再按文档落地。

方案文档位置：

```text
待重构插件/WorldListTrashCan重构/docs/世界垃圾桶区块加载性能方案.md
待重构插件/WorldListTrashCan重构/refactor-workspace/docs/世界垃圾桶区块加载性能方案.md
```

### 已补齐旧功能

- 玩家防丢弃模式：`/blwtc dropmode`，兼容 `WorldListTrashCan.DropMode`。
- 查询功能：`/blwtc look`，可查询手持物品和右键实体类型。
- 单世界黑名单 GUI：`/blwtc ban`。
- 公共垃圾桶全局黑名单 GUI：`/blwtc globalban`。
- 聊天和命令限频：读取 `protections.yml`。
- 不可拾取箭矢清理和防踩踏农田。
- 实体清理扩展：经验球、怪物、动物、投射物、自定义名、船内实体、白名单/黑名单，支持 `*` 通配。
- 世界实体数量限制和密集实体限制：读取 `entity-limits.yml`。
- 公共垃圾桶日志、公共垃圾桶按清理次数刷新、公共垃圾桶黑名单。
- 定时清理倒计时通知：Chat、ActionBar、Title、Sound、Command，读取 `notify.yml`。
- 后台测试入口：`/blwtc debugplayer <玩家> <dropmode|look|ban|globalban>`，用真实在线 `Player` 对象调用正式玩家入口。

### 构建修正

手工 `javac` 参数文件必须使用 UTF-8 无 BOM。跨版本构建还必须按目标运行时指定 `--release`：

```text
Legacy/Core/Config/Storage/Shared/LegacyPlatform/LegacyPlugin: --release 8
PaperPlatform/PaperPlugin: --release 17
```

之前只用本机 JDK 编译通过时，1.12.2 Java 8 测试服会因为 class 文件版本过高报 `UnsupportedClassVersionError`。本轮已改为按目标运行时打包。

## 2026-06-01 Bukkit 1.13-1.15 与 Folia 旧功能入口实现

### 本轮目标

用户要求先处理第三项，即 `bukkit-1_13_1_15` 与 `folia-1_20` 不再只停留在模块边界，同时继续以旧功能覆盖为主，不优先做世界垃圾桶区块加载优化。

### 已完成

- 新增 Bukkit/Spigot 1.13-1.15 平台实现：
  - `BukkitPlatform`
  - `BukkitItemSnapshotMapper`
  - `BukkitEntitySnapshotMapper`
- 新增 Bukkit/Spigot 1.13-1.15 插件入口：
  - `BLWorldTrashCanBukkitPlugin`
  - `BLWorldTrashCanBukkitCommand`
  - `BLWorldTrashCanBukkitExpansion`
  - `BukkitVaultPaymentService`
- 新增 Folia 1.20 平台实现：
  - `FoliaPlatform`
  - `FoliaSchedulerAdapter`
  - `FoliaItemSnapshotMapper`
  - `FoliaEntitySnapshotMapper`
- 新增 Folia 1.20 插件入口：
  - `BLWorldTrashCanFoliaPlugin`
  - `BLWorldTrashCanFoliaCommand`
  - `BLWorldTrashCanFoliaExpansion`
  - `FoliaVaultPaymentService`
- 为 Bukkit/Folia 两条产物补齐默认配置、`plugin.yml`、`platform.yml`、命令、权限、Vault 和 PlaceholderAPI 适配。
- 修正 shared-bukkit 的农田判断：不再直接引用 `Material.SOIL`，改为字符串兼容 `SOIL`、`FARMLAND`、`LEGACY_SOIL`，避免 1.13+ 运行时出现 `NoSuchFieldError`。
- Bukkit 1.13-1.15 产物不使用 PDC 玩家标记，避免 1.13 缺少 PDC API 导致运行时缺类；个人垃圾桶路由服务仍保留，玩家主动丢弃 owner 标记能力只在现代 Paper/Folia 产物提供。
- Folia 产物接入 `GlobalRegionScheduler`，当前不声明 `FOLIA_REGION_SAFE`；完整 region-safe 清理仍需要 Folia 实服后续验证和必要重构。
