### 1.12.2 测试服验证

部署产物：

```text
paper-1.12.2-test-server/plugins/BLWorldTrashCan-legacy-1.12.jar
```

真实客户端：

```text
client-1.12.2
玩家名: AIAutoTest
服务器: 127.0.0.1:25565
```

RCON 验证命令：

```text
list
plugins
blwtc platform
blwtc debugsummary AIAutoTest
blwtc debugworldtrash AIAutoTest
blwtc debugroute AIAutoTest world STONE 3
blwtc debugroute AIAutoTest personal DIRT 4
blwtc debugroute AIAutoTest global COBBLESTONE 5
blwtc debugsummary AIAutoTest
blwtc debugdrop AIAutoTest SAND 6 owner
blwtc clear
blwtc stats
blwtc debugsummary AIAutoTest
blwtc debugopen AIAutoTest global
blwtc debugopen AIAutoTest personal
```

关键结果：

- `plugins` 显示 `BLWorldTrashCan` 已启用。
- `platform` 显示当前平台为 `legacy-1.12`。
- `debugworldtrash` 成功创建并登记测试世界垃圾桶。
- `debugroute world` 成功写入世界垃圾桶。
- `debugroute personal` 成功写入个人垃圾桶。
- `debugroute global` 成功写入公共垃圾桶。
- `debugsummary` 显示世界垃圾桶、公共垃圾桶、个人垃圾桶均有物品数量。
- `debugdrop` 生成真实掉落物后，`clear` 将掉落物回收到世界垃圾桶，统计为 `回收物品 2 (世界 2, 个人 0, 公共 0)`。
- `debugopen` 对在线玩家成功返回，客户端日志确认 `AIAutoTest` 已连接测试服。

### 已知问题和限制

- 1.12 Legacy 不支持 PDC，因此玩家主动丢弃物的长期 owner 标记不可用；本轮通过 `debugroute personal` 验证个人垃圾桶服务和路由写入。
- 打开 GUI 时 EasyCore 报 `NoClassDefFoundError: top/wcpe/wcneteasemodrpc/item/texture/match/TextureMatchs`，这是测试服 EasyCore 前置缺类导致的 `InventoryOpenEvent` 监听异常；BLWorldTrashCan 自身命令返回成功，且服务端 debug 日志有本插件调用记录。
- 现代 Paper 产物已编译打包，但当前本机没有 1.16+ / 1.20 测试服，尚未做启动 smoke。
- `bukkit-1_13_1_15` 与 `folia-1_20` 当前仍是模块边界占位，后续需要对应测试服和 API 后再实现。
