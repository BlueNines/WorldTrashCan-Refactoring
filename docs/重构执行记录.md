### 首轮失败

首次启动暴露真实兼容错误：

```text
java.lang.NoSuchFieldError: Class org.bukkit.Material does not have member field 'org.bukkit.Material STAINED_GLASS_PANE'
```

原因是公共垃圾桶 GUI 背景直接引用了旧版本枚举 `Material.STAINED_GLASS_PANE`。该枚举在 1.20.4 已不存在，属于跨版本共享层不能直接引用的 API 差异。

修复：

- `GlobalTrashService` 不再直接引用 `Material.STAINED_GLASS_PANE`。
- 改为按字符串顺序解析 `BLACK_STAINED_GLASS_PANE`、`STAINED_GLASS_PANE`、`LEGACY_STAINED_GLASS_PANE`、`GRAY_STAINED_GLASS_PANE`、`GLASS_PANE`、`THIN_GLASS`。
- 所有候选都不可用时退回 `Material.STONE`。

- `CleanupFeature`：当平台 id 以 `folia` 开头且未声明 `FOLIA_REGION_SAFE` 时，定时世界扫描不启动，`runNow()` 只刷新公共垃圾桶状态并跳过实体扫描。
- `BLWorldTrashCanFoliaPlugin`：暴露 `isCleanupScanSupported()`。
- `BLWorldTrashCanFoliaCommand`：`/blwtc clear` 在未支持 region-safe 时直接拒绝执行，并提示管理员。
