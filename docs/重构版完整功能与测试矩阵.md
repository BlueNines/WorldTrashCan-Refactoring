## 测试结果记录规则

每轮完整回归都要产出：

- `summary.json`：按功能 ID 写出 `PASS`、`FAIL`、`SKIP` 或 `STATIC-PASS`。
- `server-console.log`、`console-commands.log`、`client-stdout.log`、`client-stderr.log`。
- 玩家可见功能的 F2 截图。
- 被临时修改配置的备份。
- 本文档中未被运行态覆盖的功能必须写明原因，不能把“没测”混成“通过”。

`PASS` 只用于本轮真实执行过的运行态功能；`STATIC-PASS` 只用于核心纯 Java 策略、jar 内容或源码结构可以完全证明的功能；`SKIP` 只用于默认关闭且本轮没有配置前置、或者目标端不适用的功能。
