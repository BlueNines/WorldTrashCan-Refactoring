## 已确认但需要避免回退的行为

- `/wtc clear`、`/blwtc clear` 默认等价 `true`，会忽略 guards；传入 `false` 时才遵守 guards。
- `guards.min-total-entities` 默认值是 `150`。
- `global-trash.clear-every-cleanups` 触发时必须先清空旧公共垃圾桶，再收集本轮物品。
- 新版本物品入桶必须保留原物品，不允许因 legacy material 映射或日志异常丢失。
- 密集实体 `remove-count` 表示触发后本轮最多清理多少只，不是只清理超出上限的差值。
- 密集实体候选队列是一次性消费队列，不是长期状态表。
- 公共黑名单 GUI 使用 token 点击模型：点击玩家背包物品复制 Material token，不消耗物品；点击上方 token 删除；关闭 GUI 后保存并刷新运行期配置。
- 外部语言文件缺节点时优先回退当前语言的 jar 内置节点，再回退默认中文；旧外部语言主帮助包含调试命令时也必须使用当前语言的 jar 内置主帮助。
- Vault 扣费只用于个人垃圾桶取出；必须先确认物品能完整进入玩家主背包存储槽，再调用 Economy 扣费，余额不足或背包满都不能产生扣款。
- Evidence 目录中的备份 jar 只作为本地恢复缓存，不提交到 Git；最终证据只记录被测 jar 文件名、版本和 SHA256。
