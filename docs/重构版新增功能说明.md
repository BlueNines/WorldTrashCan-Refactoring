# BLWorldTrashCan 重构版新增功能说明

本文面向服主和做服技术，说明重构版相对旧 `WorldListTrashCan` 多出的功能和主要增强点。旧插件原有的世界垃圾桶、公共垃圾桶、个人垃圾桶、清理通知、黑名单、保护功能等仍按兼容目标保留；这里重点只列重构版新增或明显增强的内容。

## 新增功能

### 轻量分包和通用总包

重构版同时提供两种交付形态：

- `BLWorldTrashCan-legacy-1.12.jar`：面向 Paper/Spigot 1.12.2。
- `BLWorldTrashCan-bukkit-1.13-1.15.jar`：面向 Bukkit/Spigot 1.13-1.15。
- `BLWorldTrashCan-paper-1.16-1.20.jar`：面向现代 Paper。
- `BLWorldTrashCan-folia-1.20.jar`：面向 Folia 1.20。
- `BLWorldTrashCan-universal.jar`：通用总包，面向希望一个 jar 在高低版本和 Folia 之间切换的服主。

四个轻量分包仍是最小包体、最少运行时判断的推荐形态；通用总包保留同一套平台模块，但主类用 Java 8 编译，并在运行时延迟加载对应实现。这样既保留服主“一个 jar”使用习惯，也避免把 Legacy、Paper、Folia 差异堆在同一份运行逻辑里。

### Folia 专用安全清理链路

重构版新增 Folia 专用清理实现：

- `/blwtc clear` 在 Folia 产物中改为异步启动语义。
- 世界实体扫描按 region/entity scheduler 分段执行。
- 物品删除、玩家通知等涉及实体或玩家的动作尽量提交到对应实体上下文。
- Folia 专用实体数量限制不使用普通 Bukkit 的跨 region 扫描。

注意：Folia 产物已完成后台 smoke，但 BossBar、Title、Sound 等玩家视觉通知还没有完整客户端视觉验收，因此当前不声明整包完全 `FOLIA_REGION_SAFE`。

### 扫地启动门禁

重构版新增扫地启动门禁，避免无人或低实体压力时仍触发完整扫地：

```yaml
guards:
  min-online-players: 1
  min-total-entities: 400
```

- `min-online-players`：在线玩家低于该值时跳过本轮扫地，默认 `1`，表示无人在线不扫地。
- `min-total-entities`：会被本轮扫地处理的目标实体数量低于该值时跳过本轮扫地，默认 `400`。
- 设置为 `0` 可关闭对应门禁。
- `/blwtc clear` 和 `/blwtc stats` 会显示最近一轮门禁状态；自动扫地被门禁跳过时会发送 `cleanup.yml` 中 `notify.*.messages` 的 `-5` 提示。
- 普通 Bukkit/Paper/Legacy 端在达到阈值前只暂存少量候选实体，达到阈值后继续清理，避免为了门禁做完整二次扫描；Folia 端按 RegionScheduler 先做安全计数，达到阈值后再进入清理阶段。

### 默认阻止世界垃圾桶强制加载区块

旧版世界垃圾桶可能在清理时访问未加载区块，导致同步加载区块并造成卡顿。重构版新增默认保护：

```yaml
world-trash:
  allow-load-unloaded-chunks: false
```

默认情况下，如果世界垃圾桶所在区块未加载，清理任务会跳过该箱子并按路由降级，而不是强行加载区块。

### 拆分配置文件和中文注释

重构版把旧的大配置拆成多份文件：

- `config.yml`
- `cleanup.yml`：清理周期、清理规则和清理通知。
- `trash.yml`
- `entity-limits.yml`
- `protections.yml`
- `platform.yml`
- `messages/message_*.yml`
- `data/worlds.yml`

默认配置均带中文注释，更适合后续维护、迁移和排查。

### 旧配置自动迁移

重构版会尝试读取旧 `WorldListTrashCan` 配置并迁移到新拆分结构：

- 支持从当前 `plugins/BLWorldTrashCan` 或相邻 `plugins/WorldListTrashCan` 读取旧配置。
- 迁移前会备份旧文件。
- 迁移后生成 `legacy-migration-report.md`。
- 已承接主配置、清理配置、通知配置、保护配置、实体限制配置、公共/个人/世界垃圾桶配置，以及旧世界垃圾桶运行数据。

### 多语言消息服务

重构版新增统一消息服务，支持：

- 简体中文：`message_zh.yml`
- 繁体中文：`message_zh_TW.yml`
- 英文：`message_en.yml`
- 西班牙语：`message_es.yml`

如果旧服已有外部语言文件但缺少新节点，正式玩家文案会回退到 jar 内默认节点，减少升级后提示空白的问题。

### 1.16.5+ RGB 富文本消息

重构版新增统一富文本渲染入口，1.16.5+ 服务端支持 `&#RRGGBB` 这类 RGB 写法。当前实现使用 PrismaticAPI `1.5.2` 并内置 relocation，覆盖普通聊天、可点击聊天、ActionBar、Title、BossBar 标题、GUI 标题和平台层玩家消息。2026-06-07 已用真实原版客户端 F2 截图覆盖 Paper 1.12.2、1.13.2、1.14.4、1.15.2、1.16.5、1.17.1、1.18.2、1.19.4、1.20.4 和 1.21.4；低版本为传统色降级截图，1.16.5+ 为 RGB 截图。随后补充外部服务端矩阵，覆盖 Paper 1.21.8、CatServer 1.12.2、Folia 1.21.8、Paper 1.21.11、Arclight NeoForge 1.21.1 和 Banner/Fabric 1.20.1，均以真实客户端 F2 截图和 `blwtc platform` 命令接受校验判定通过。最新 universal 整包复测中，6 个外部服务端全部部署同一个 `BLWorldTrashCan-universal.jar`，RGB 证据限定聊天框、ActionBar、Title/Subtitle，不使用箱子 GUI 或物品 Lore；每端 11 项基础功能检查全部 PASS。针对 Title 颜色人工观感接近传统 `&a`、`&6` 的问题，已追加高辨识度 RGB 复测，Title 显示多段 `RGB TITLE FF1493`，Subtitle 显示 `SUBTITLE FF4F00`，6 个外部端再次全部 PASS。2026-06-08 又补充 Paper 26.1.2 与 Spigot 26.1.2 两端验收，两个服务端均部署同一个 `BLWorldTrashCan-universal.jar`，使用真实 26.1.2 客户端截图验证 Chat、ActionBar、Title/Subtitle RGB，并执行 11 项基础功能检查，全部 PASS。可提交截图证据目录：`docs/test-evidence/rgb-visual-proof-20260607-104606/`、`docs/test-evidence/rgb-external-server-proof-20260607-155341/`、`docs/test-evidence/rgb-universal-channels-proof-20260607-175511/`、`docs/test-evidence/rgb-universal-highcontrast-channels-proof-20260607-202234/`、`docs/test-evidence/rgb-26-1-spigot-paper-proof-20260608-005225/`。

低版本行为：

- 1.12.2：降级为传统 `&` 颜色码，不支持真实 RGB。
- 1.13-1.15：降级为传统 `&` 颜色码，不支持真实 RGB。

注意：BossBar 标题文本可以 RGB，BossBar 条本身仍只能使用 Bukkit `BarColor` 枚举颜色。

### 个人垃圾桶自动回收提示

旧版公共垃圾桶已有提示，重构版新增个人垃圾桶自动回收提示：

- 单个掉落实体被仙人掌、岩浆、虚空等损坏回收时，逐条提示。
- `/blwtc clear` 或后台扫地一次回收多个掉落物时，合并为一次批量提示。
- 批量提示最多展示多少类物品可在 `trash.yml` 配置。
- 物品列表格式、分隔符、省略号都可在语言文件配置。

示例：

```text
[BLWorldTrashCan] 已回收到个人垃圾桶: [STONE*2]
[BLWorldTrashCan] 本次清理已回收到个人垃圾桶: [STONE*5, COBBLESTONE*30, DIRT]
[BLWorldTrashCan] 本次清理已回收到个人垃圾桶: [STONE*5, COBBLESTONE*30, DIRT, ...]
```

### 玩家丢弃物归属追踪增强

重构版增强了玩家主动丢弃物进入个人垃圾桶的判断：

- Legacy 1.12 和 Bukkit 1.13-1.15 没有 PDC，因此使用短期运行态 owner 追踪。
- Paper/Folia 优先使用掉落实体 PDC 标记 owner。
- Paper/Folia 的 owner 标记写在掉落实体上，不写入 `ItemStack` 元数据，避免隐藏 PDC 影响物品正常叠加。
- 入库前会清理旧版本残留在物品元数据上的内部标记。

### 仙人掌、岩浆、虚空损坏回收模式

重构版把旧损坏回收行为拆成明确配置：

```yaml
personal-trash:
  damage-recovery:
    mode: "disabled"
    delay-seconds: 6
```

`mode` 可配置为：

- `disabled`：关闭。
- `global-trash`：进入公共垃圾桶。
- `personal-trash`：进入玩家个人垃圾桶。

### PAPI 变量覆盖到多平台产物

重构版四个平台代码都提供旧变量：

```text
%Wtc_ClearTime%
```

该变量返回下次自动清理剩余秒数。Legacy、Bukkit、Paper 已完成运行态验证；Folia 需要安装支持 Folia 的 PlaceholderAPI 前置后再验收。

### bStats 统计接入

重构版接入 bStats，沿用旧插件 serviceId `24350`，并新增 `platform` 图表用于区分当前运行产物：

- `legacy-1.12`
- `bukkit-1.13-1.15`
- `paper-1.16-1.20`
- `folia-1.20`

本插件不提供单独 bStats 开关，只使用 bStats 官方全局配置。

2026-06-08 已使用 `7.0.0` 构建验证 bStats 真实生效：`plugin.yml` 版本通过 Maven `${project.version}` 过滤生成，五个交付 jar 均为 `version: 7.0.0`；测试服上报 bStats serviceId `24350` 时，数据包包含 `pluginVersion=7.0.0`，bStats 返回响应，并且页面 `Plugin Version` 图表刷新后出现 `7.0.0`。

### 后台测试命令更完整

重构版新增和保留了一批后台测试入口，方便服主或开发者验证真实运行态。调试命令不会在 `/blwtc help` 主面板里完整展开，需单独使用：

```text
/blwtc debughelp
```

`/blwtc debughelp` 会展示：

```text
/blwtc debugopen <玩家> <global|personal>
/blwtc debugworldtrash <玩家>
/blwtc debugroute <玩家> <world|personal|global> <Material> <数量>
/blwtc debugdrop <玩家> <Material> <数量> [owner]
/blwtc debugdamage <玩家> <Material> <数量>
/blwtc debugstock
/blwtc debugsummary <玩家>
/blwtc debugplayer <玩家> <dropmode|look|ban|globalban>
/blwtc debugrgb <玩家>
/blwtc debugrgbchannels <玩家>
```

这些命令用于验收和排查，不建议作为普通玩家功能开放。

## 兼容增强

### 旧命令和旧权限兼容

重构版兼容旧命令入口：

```text
/WorldListTrashCan
/WTC
/wtc
```

同时兼容旧权限节点，例如：

- `WorldListTrashCan.Main`
- `WorldListTrashCan.GlobalTrashOpen`
- `WorldListTrashCan.PlayerTrash`
- `WorldListTrashCan.GlobalTrashTakeItem`
- `WorldListTrashCan.PersonalTrashTakeItem`
- `WorldListTrashCan.DropMode`
- `WorldListTrashCan.Look`

### OP 旁路行为恢复

旧插件中 OP 通常可以绕过部分权限限制。重构版已在命令和公共/个人垃圾桶 GUI 取放物品等路径恢复 OP 旁路，减少旧服迁移后的权限差异。

### 世界垃圾桶上限运行数据生效

重构版让 `/blwtc add <世界名> <数量>` 写入的 `data/worlds.yml` 上限参与正式创建判断，不再只验证文件落盘。

### 公共黑名单保存即时生效

公共黑名单 GUI 保存后会刷新运行期配置，不再要求服主手动 `/blwtc reload` 才完全生效。

### 实体清理总开关补齐

旧配置里的实体清理总开关已迁移为：

```yaml
entities:
  enabled: true
```

关闭后，经验球、怪物、动物、投射物和实体黑名单等实体清理会整体跳过。

## 当前注意事项

- Folia 的 PAPI 变量需要支持 Folia 的 PlaceholderAPI 前置；本机 PlaceholderAPI 2.11.6 不支持 Folia。
- Folia 的 BossBar、Title、Sound 玩家视觉通知仍建议后续做真实客户端视觉验收。
- PrismaticAPI 当前按 `GPL-3.0-only` 许可证接入，本重构版按后续开源基础版发行前提使用；如果未来要做不满足 GPL-3.0-only 要求的闭源发行，需要重新评估 RGB 库或改为外置依赖。
- Folia 密集实体限制为避免跨 region 查询，只扫描当前 chunk 范围。
- `debug*` 命令会改变测试服运行态，只建议用于测试服。
- 混用旧外部配置时，建议先备份 `plugins/WorldListTrashCan` 和 `plugins/BLWorldTrashCan`。
